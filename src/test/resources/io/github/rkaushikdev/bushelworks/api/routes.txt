# Every route the application answers on, written down: a method and a path on each line.
#
# A route is a promise. The scale terminal, the office screen and the producer portal all have
# this list compiled into them, and a path that quietly changes shape breaks a client nobody is
# going to redeploy this week.
#
# So the surface is fixed here and ApiSurfaceTest compares it. Adding a route means adding a
# line, which is the point: it is one line of thought about whether the path is the one you want
# to live with. The list is sorted by path; the test checks separately that no route is shadowed
# by one beside it.
